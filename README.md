# CA Infrastructure & Network Security System

A university project building a Linux-based network security environment 
with a custom Certificate Authority (CA) system.

## What this covers
- Set up a Linux-based network environment with Apache2, BIND9 (DNS), 
  OpenSSH, a firewall, and an intrusion detection system (IDS)
- Built a certificate authority hierarchy — Root CA, and DV/OV/EV Sub-CAs — 
  with certificate issuance and revocation using OpenSSL
- Developed a web-based CA management application with user authentication, 
  certificate requests, administrator controls, and ownership-based 
  authorization
- Performed security testing and network analysis using Nmap, Wireshark, 
  and controlled IDS testing; validated the web app's APIs using Postman
